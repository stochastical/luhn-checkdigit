# luhn-checkdigit

Generate a million+ character regular expression to validate credit card numbers with the [Luhn check digit algorithm](https://en.wikipedia.org/wiki/Luhn_algorithm).

For further details and explanation, please read the article on my blog: [Can a regex match valid card numbers?](https://abstractnonsense.xyz/blog/2025-08-31-can-a-regex-match-valid-card-numbers/)
